# Dxien Studio

Dxien Studio es un proyecto personal de desarrollo web y freelancing enfocado en crear soluciones web limpias, responsivas y funcionales para pequeños negocios, proyectos y marcas.

Actualmente el enfoque principal está en desarrollo frontend, landing pages, sitios web para pequeños negocios y mejoras de experiencia visual y responsive.

El proyecto evolucionará progresivamente hacia soluciones web más completas a medida que se incorporen nuevas tecnologías y proyectos de referencia.

## Objetivo

Construir una presencia profesional como desarrollador web mediante proyectos reales y demostrativos, documentación clara y un portafolio que refleje habilidades comprobables.

Dxien Studio también funciona como base para ofrecer servicios freelance en plataformas como Workana, Upwork y otros canales profesionales.

## Servicios actuales

1. Landing pages responsivas.
2. Sitios web simples para pequeños negocios.
3. Mejoras y ajustes de frontend.
4. Optimización de diseño responsive.
5. Portafolios y sitios web personalizados.
6. Revisión y mejora de estructura visual de páginas existentes.

## Tecnologías actuales

- HTML
- CSS
- JavaScript
- Git
- GitHub

El portafolio se ampliará progresivamente con proyectos que incorporen nuevas tecnologías de frontend, backend y desarrollo full-stack.

## Proyectos

Los proyectos publicados en este repositorio pueden incluir proyectos de demostración, prácticas convertidas en piezas de portafolio y desarrollos propios.

Cada proyecto indicará claramente si corresponde a:

- proyecto de demostración;
- proyecto académico;
- proyecto personal;
- proyecto realizado para un cliente.

No se presentarán proyectos ficticios como trabajos reales de clientes.

## Principios profesionales

Dxien Studio busca mantener una comunicación clara y responsable.

No se prometen ventas, ingresos, conversiones, posicionamiento SEO ni resultados financieros garantizados.

Las recomendaciones y servicios se enfocan en mejorar aspectos como:

- estructura;
- claridad;
- experiencia de usuario;
- presentación visual;
- diseño responsive;
- funcionalidad;
- mantenibilidad.

## Evolución

Dxien Studio está diseñado para crecer junto con mis habilidades como desarrollador.

Conforme se desarrollen y publiquen proyectos más avanzados, el portafolio podrá incorporar áreas como:

- desarrollo backend;
- APIs;
- bases de datos;
- aplicaciones web;
- arquitectura frontend/backend;
- desarrollo full-stack.
