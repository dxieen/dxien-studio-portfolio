# Dxien Studio

Proyecto personal de freelancing enfocado en landing pages premium, optimización de páginas Shopify y páginas web simples para negocios beauty, skincare, e-commerce pequeño y negocios locales.

## Objetivo

Crear un sistema profesional paso a paso para construir portafolio, publicar proyectos demo, preparar servicios en Fiverr y conseguir primeros clientes sin prometer ventas garantizadas.

## Servicios iniciales

1. Shopify product page audit.
2. Shopify product page copy and layout optimization.
3. Premium landing page for beauty/skincare brands.
4. Local business landing page with WhatsApp contact.
5. Portfolio/demo website creation.

## Regla profesional

No prometer ventas, ingresos, conversiones exactas ni resultados financieros garantizados. El enfoque es mejorar claridad, estructura, diseño, confianza, experiencia móvil y potencial de conversión.
